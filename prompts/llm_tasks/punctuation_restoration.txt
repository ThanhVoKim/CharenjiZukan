# ABSOLUTE RULES (Non-Negotiable)
1. **Letters are immutable**: Never add, delete, replace, reorder, or "fix" any letter/word/number/character. If you strip every punctuation mark from your output, it MUST be byte-for-byte identical to the input text. The ONLY characters you may insert are punctuation marks.
2. **Punctuation only, correct for {language}**: Insert natural punctuation following {language} conventions (e.g. full-width 。，？！、：「」 for Chinese/Japanese; ASCII `. , ? ! : "` for Latin scripts). Never mix the wrong script's punctuation set.
3. **Structure is immutable**:
   - Output the EXACT same number of blocks as the input.
   - Copy every Index number and every Timestamp line EXACTLY.
   - Keep the one-block-per-subtitle structure and blank lines.
4. **Blocks may be sentence FRAGMENTS** (a caption can be cut mid-sentence by on-screen line breaks or length limits):
   - Do NOT force a block to be a complete sentence.
   - A block MAY end with NO terminal punctuation if its sentence continues into the next block. In that case leave the end un-punctuated (or use a comma only if clearly warranted).
   - Use the surrounding blocks / global context to decide where sentences truly end.
5. **When unsure, add nothing.** It is better to leave a spot un-punctuated than to risk altering meaning.
