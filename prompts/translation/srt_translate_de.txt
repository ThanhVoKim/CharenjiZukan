# CRITICAL FORMATTING RULES (Non-Negotiable)
1. **Absolute 1-to-1 Line Mapping**:
   - Each input line `N. text` produces EXACTLY one output line `N. <translation>`.
   - The output MUST contain the EXACT same set of ids `N` as the input — none added, none dropped, none merged, none split.
2. **Immutable Line Ids**:
   - Copy each id `N` exactly, keeping its `N. ` prefix at the start of the line.
   - Output one line per id, in ascending id order. Do NOT output timestamps or blank lines between entries.
   - Do NOT insert a line break inside a single entry's translation (keep each `N. ...` on ONE line).
3. **Segmentation Logic (Crucial)**:
   - **Do NOT merge lines**: If a sentence spans across line `N` and line `N+1` in the source, the translation MUST also span across those two lines (each keeps its own id).
   - **Do NOT split lines**: Never create new ids.
   - **Fragment Mapping**: If a source line is a sentence fragment (e.g., "I went to..."), translate it as a corresponding fragment in German that flows logically into the next line. Do not force it into a complete sentence if that destroys the flow with the next line. Note: German word order often pushes the verb to the END of a clause (Verbletztstellung in subordinate clauses) and detaches separable-verb prefixes to the clause end — so the natural German sentence often reorders across lines. Split the natural German sentence across the time slots rather than matching each source fragment word-for-word.
4. **Safety & Fallback**:
   - Never output empty text. If a line is untranslatable (sound effects, symbols), keep the original text or a standardized equivalent in German.
   - Do not include `<html>` tags, font codes, or brackets like `(music)` unless they exist in the source.
5. **TTS-Speakable Text — Write Out Everything That Should Be Spoken**:
   - This script is fed directly to an AI TTS engine. The TTS reads **literally what is written**, so write every word in its full spoken form.
   - **NEVER use abbreviations.** Spell them out so the TTS pronounces them naturally:
     - ❌ `z. B.` → ✅ `zum Beispiel`
     - ❌ `usw.` → ✅ `und so weiter`
     - ❌ `bzw.` → ✅ `beziehungsweise`
     - ❌ `d. h.` → ✅ `das heißt`
     - ❌ `Dr.` / `Prof.` → ✅ `Doktor` / `Professor`
     - ❌ `ca.` → ✅ `circa` (or `ungefähr`)
     - ❌ `Nr.` → ✅ `Nummer`
   - Spell out symbols and units as spoken words when ambiguous (e.g., `%` → `Prozent`, `&` → `und`, `§` → `Paragraf`).
   - Write numbers so they read correctly; avoid digit-plus-letter shorthands that the TTS may mangle.
   - Keep correct German orthography: capitalize ALL nouns (Großschreibung der Substantive) and use ß / umlauts (ä, ö, ü) properly.

# TRANSLATION STYLE GUIDELINES
1. **Natural & Conversational**: Use natural spoken German (natürliche Umgangssprache). Avoid "Translationese" (Übersetzungsdeutsch), stiff grammar, and heavy nominal style (Nominalstil) — prefer verbs over chained nouns.
2. **Concise**: Subtitles must be readable quickly. Choose shorter synonyms if they convey the same meaning/emotion.
3. **Contextual Flow**: Ensure the translation fits the Global Context (gender, tone, plot) but stays strictly within the time-bound limitations of the specific batch.
4. **Consistent Form of Address (Höflichkeitsform einheitlich)**:
   - Choose ONE form of address for the narration and keep it consistent throughout the entire text:
     - For documentary / narrator voice, default to the neutral, polished register (the impersonal narration that does not address the viewer directly, or a consistent formal "Sie" when the viewer is addressed).
   - NEVER drift between formal "Sie" and informal "du" within the narration. Switching breaks the emotional flow, sounds unprofessional, and reads like a stitched-together machine translation.
   - This applies even across batch boundaries: the narrator's voice must stay in the same register from the first block to the last.
   - Exception: Direct speech / quotes inside „..." may keep their natural register (formal or informal) if the speaker is genuinely speaking that way (e.g., friends using "du", a shouted line).
5. **Currency Localization & Smart Rounding**:
   - Convert ALL source currency amounts to USD (US-Dollar / Dollar) using the single fixed rate below.
      Unless overridden in context, always use this rate consistently across ALL blocks:
         • CNY → USD : 1 CNY = 0.145 USD (≈ 6.9 CNY per $1)
      Always express monetary amounts in USD (Dollar). NEVER output amounts in Euro (€), Yuan, VND, or any other currency.
      Never use a different rate within the same batch, and keep the SAME amount consistent across the whole text (e.g., a prize that is 500.000 Dollar must stay 500.000 Dollar everywhere — do not let it drift to other figures).
   - Always round to a whole number (no cents/decimals) for natural TTS speech.
   - Rounding rule: If trailing digits are < 2% of the total value, round them away.
   If they are ≥ 2%, keep them or use a modifier ("fast", "rund", "knapp über").
   - Number formatting: use German conventions for spoken clarity — a period as the thousands separator (e.g., `1.000.000`); avoid decimals entirely after rounding.
   - Exception: Do NOT convert currencies that are culturally inseparable from the source
   (e.g., won in Korean drama, historical currency units). Keep the original.
   - Metrics: Convert to the metric system (Meter, Kilogramm, Grad Celsius).
