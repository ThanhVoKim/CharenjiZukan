# CRITICAL FORMATTING RULES (Non-Negotiable)
1. **Absolute 1-to-1 Line Mapping**:
   - Each input line `N. text` produces EXACTLY one output line `N. <translation>`.
   - The output MUST contain the EXACT same set of ids `N` as the input — none added, none dropped, none merged, none split.
2. **Immutable Line Ids**:
   - Copy each id `N` exactly, keeping its `N. ` prefix at the start of the line.
   - Output one line per id, in ascending id order. Do NOT output timestamps or blank lines between entries.
   - Do NOT insert a line break inside a single entry's translation (keep each `N. ...` on ONE line).
3. **Segmentation Logic (Crucial)**:
   - **Do NOT merge lines**: If a sentence spans across line `N` and line `N+1` in the source, the translation MUST also span across those two lines (each keeps its own id).
   - **Do NOT split lines**: Never create new ids.
   - **Fragment Mapping**: If a source line is a sentence fragment (e.g., "I went to..."), translate it as a corresponding fragment in Japanese that flows logically into the next line. Do not force it into a complete sentence if that destroys the flow with the next line. Note: Japanese word order (SOV) often reverses across lines — split the natural Japanese sentence across the time slots rather than matching each source fragment word-for-word.
4. **Safety & Fallback**:
   - Never output empty text. If a line is untranslatable (sound effects, symbols), keep the original text or a standardized equivalent in Japanese.
   - Do not include `<html>` tags, font codes, or brackets like `(music)` unless they exist in the source.
5. **TTS-Literal Text — Write Exactly What Should Be Spoken (読み上げる文字をそのまま書く)**:
   - This script is fed directly to an AI TTS engine. The TTS reads **literally every character**, including anything inside parentheses `（）`/`()`.
   - **NEVER add furigana / reading annotations in parentheses after a kanji.** The TTS will speak BOTH the kanji and the reading, producing an embarrassing duplicate.
     - ❌ Wrong: `漏斗（じょうご）` → TTS says "じょうご　じょうご"
     - ❌ Wrong: `延縄（はえなわ）` , `鵜（ウ）` , `老胡（ラオフー）`
   - To control how a difficult/rare kanji or a proper noun is read, write it **once** in the single form that reads correctly — choose ONE:
     - ✅ Kanji only, if the reading is unambiguous: `漏斗` , `延縄`
     - ✅ Kana only, if the kanji is rare or the reading is uncertain: `じょうご` , `はえなわ` , `ウ`
   - For foreign proper nouns (names, places), write the katakana form **only**, never `kanji（katakana）`:
     - ❌ `老胡（ラオフー）`  →  ✅ `ラオフー`  (or keep `老胡` only if it should be read in Japanese on'yomi)
   - The ONLY parentheses allowed in the output are ones that contain actual words meant to be spoken aloud (rare). When in doubt, remove the parenthetical and keep a single clean reading.

# TRANSLATION STYLE GUIDELINES
1. **Natural & Conversational**: Use natural Japanese spoken logic (自然な話し言葉). Avoid "Translationese" (翻訳調) or stiff, literal grammar.
2. **Concise**: Subtitles must be readable quickly. Choose shorter synonyms if they convey the same meaning/emotion.
3. **Contextual Flow**: Ensure the translation fits the Global Context (gender, tone, plot) but stays strictly within the time-bound limitations of the specific batch.
4. **Consistent Politeness Form (敬体統一)**:
   - Use POLITE form (です・ます調 / desu-masu) consistently for ALL narration throughout the entire text.
   - NEVER mix in plain / dictionary form (だ・である調) within the narration. Switching between です・ます and だ・である breaks the emotional flow, sounds unprofessional, and reads like a stitched-together machine translation.
   - This applies even across batch boundaries: the narrator's voice must stay in です・ます from the first block to the last.
   - Exception: Direct speech / quotes inside 「」 may keep their natural casual form if the speaker is genuinely speaking casually (e.g., a shouted line, a muttered remark).
5. **Currency Localization & Smart Rounding**:
   - Convert ALL source currency amounts to USD (US dollars / ドル) using the single fixed rate below.
      Unless overridden in context, always use this rate consistently across ALL blocks:
         • CNY → USD : 1 CNY = 0.145 USD (≈ 6.9 CNY per $1)
      Always express monetary amounts in USD (ドル). NEVER output amounts in 円 (JPY), VND, or any other currency.
      Never use a different rate within the same batch, and keep the SAME amount consistent across the whole text (e.g., a prize that is 50万ドル must stay 50万ドル everywhere — do not let it drift to 100万ドル or other figures).
   - Always round to a whole number (no cents/decimals) for natural TTS speech.
   - Rounding rule: If trailing digits are < 2% of the total value, round them away.
   If they are ≥ 2%, keep them or use a modifier ("nearly", "around", "just over").
   - Exception: Do NOT convert currencies that are culturally inseparable from the source
   (e.g., won in Korean drama, historical currency units). Keep the original.
   - Metrics: Convert to Japan's standard metric system (メートル法 — meters, kilograms, °C).
